# 江湖行 (my_wuxia)

一款手机竖屏的水墨风回合制武侠 RPG，纯 Java + Android Canvas 实现，无第三方依赖、无音频资源文件。

## 玩法

- **四大门派，四种开局**：少林、武当、峨眉、丐帮各有专属师门地图、序章剧情、门中叛徒、出师试炼、镇派神兵；隐藏终章的影阁之主（最终首领）也因门派而异。
- **二十一处地点**：四座城镇、四处师门（只显示自己的）、十三处野外，包括无量山、楼兰古城与隐藏的归墟；地图可上下拖动。
- **分层探索**：每处野外 3～6 层，战斗胜利后深入一层，探明全境才能挑战首领；剧情目标所在地的首领会按剧情替换。
- **兵器体系**：剑 / 刀 / 棍 / 拳四类兵器，吸血、破甲、连击、寒冰、剧毒五种特效；武功与兵器相合威力 +25%；铁匠铺可强化至 +10；另有镇派神兵与陨铁神兵。
- **回合制战斗**：普攻回内力；武功分重击 / 连击 / 吸血 / 点穴 / 施毒 / 护体 / 身法 / 疗伤；敌人会下毒、摄魂（令你失神一回合）、吸血；首领半血暴怒；决战时同伴助战。
- **约三倍的剧情**：序章 + 五章 + 终章 + 隐藏终章，25 个主线节点；第三章三条线路（追查真相 / 效忠盟主 / 投身魔教）；第五章师门与苏晚晴的两难抉择。
- **十二种结局**：侠之大者、神仙眷侣、魔道至尊、盟主传人、孤剑天涯、天魔右使、影灭天明、残阳如血、影阁新主、师门传人、江湖夜雨、玉石俱焚。
- **证物与影阁线索**：8 件证物决定能否揭穿慕容渊；8 条影阁线索集齐 4 条开启隐藏终章「归墟」。
- **六条支线**：师门秘传、萧家庄旧址、晚晴的心事、镖银失踪、铸剑、影阁密信；另有客栈悬赏与十一种江湖奇遇。
- **剧情指引**：江湖志中可查看流程图与当前位置、全部结局的达成条件、线索与证物的获取方法、支线一览，以及关键抉择记录；抉择按钮会标注其影响。
- **20 个存档位 + 节点存档**：关键抉择前自动存档，可读取节点改走其他分支（覆盖重走或复制到空存档位）。
- **声音**：古筝拨弦与五声音阶旋律实时合成，城镇 / 野外 / 战斗 / 首领 / 悲伤 / 结局各有曲风，另有各类音效。

完整的剧情流程图与结局攻略见 [docs/story-v3.md](docs/story-v3.md)。

## 构建与发布

本地只做代码开发，不在本地构建。APK 由 GitHub Actions（`.github/workflows/android-apk-release.yml`）构建签名：

```bash
git tag -a v3.0.0 -m "Release v3.0.0"
git push origin v3.0.0
```

推送 `v*.*.*` 标签后，工作流会构建签名 APK，并以 `my_wuxia.apk` 的名字上传到对应 GitHub Release。签名依赖组织级 Actions 配置 `KEY_JKS`、`ALIAS`、`ANDROID_KEY_PASSWORD`、`ANDROID_STORE_PASSWORD`（工作流会自动去除这些值中的 UTF-8 BOM 与换行）。

## 代码结构

| 文件 | 说明 |
| --- | --- |
| `MainActivity` / `GameView` | 全屏 Activity 与 720 宽虚拟画布，处理音频生命周期 |
| `Game` / `Scene` / `Button` | 场景切换、触控分发、多存档、设置、结局收集 |
| `Audio` | 程序合成的背景音乐与音效 |
| `GameData` | 门派、武功、物品与兵器、敌人、地点数据（只追加，保证存档兼容） |
| `Player` / `Inventory` | 角色成长、装备加成、JSON 存档与旧版迁移、物品 / 装备 / 强化 |
| `Story` / `Ev` | 剧情引擎：章节与支线目标、证物与线索、节点存档、提示文本 |
| `StoryMain` / `StoryEnd` / `StorySide` | 序章至第四章、第五章至十二种结局、支线与奇遇的剧情文本 |
| `Sects` | 四派专属的师门、叛徒、试炼、神兵与最终首领 |
| `DialogScene` / `EndingScene` | 对白与抉择（关键节点标记）、结局卡片 |
| `GuideScene` / `NodeScene` | 剧情指引（流程 / 结局 / 线索 / 支线）、节点回溯 |
| `*Scene` | 标题、存档位、创建角色、地点、地图、战斗、客栈、集市、铁匠铺、武学、行囊、江湖志、系统 |
| `UI` / `Sprites` | 水墨风背景、面板、人物立绘与野兽绘制 |
