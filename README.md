# 江湖行 (my_wuxia)

一款手机竖屏的水墨风回合制武侠 RPG，纯 Java + Android Canvas 实现，无第三方依赖、无音频资源文件。

## 玩法

- **四大门派**：少林（血厚防高）、武当（均衡吸血）、峨眉（迅捷疗伤）、丐帮（刚猛控制），每派 5 门本门武学，另有 7 门奇遇武学。
- **十四处地点**：临安、洛阳、大理、襄阳四座城镇，以及竹林、黑风寨、终南古墓、思过崖、苗疆毒林、太湖水寨、大漠孤城、天山雪岭、黑木崖、蓬莱仙岛十处野外。
- **分层探索**：每处野外有 3～6 层，战斗胜利后深入一层，探明全境才能挑战该地首领；首领可重复挑战，首杀必掉专属兵器。
- **兵器体系**：剑 / 刀 / 棍 / 拳四类兵器，带吸血、破甲、连击、寒冰、剧毒等特效；武功与兵器类别相合时威力 +25%。另有护甲与饰品栏，铁匠铺可强化兵甲至 +10（高阶需玄铁）。
- **回合制战斗**：普攻回内力；武功分重击 / 连击 / 吸血 / 点穴 / 施毒 / 护体 / 身法 / 疗伤；敌人会下毒，首领半血暴怒。
- **分支剧情**：六章主线，人物对白配立绘，关键节点的抉择会影响侠义值、苏晚晴与萧寒的好感，以及收集到的证物。第三章分为「追查真相」与「效忠盟主」两条线路。
- **六种结局**：侠之大者、神仙眷侣、魔道至尊、盟主传人、孤剑天涯、天魔右使，结局收集跨存档记录。
- **江湖奇遇**：路见不平、魔教伤者、商队遇袭、路边赌局、饥饿老者、茶棚说书、冒名之徒、故人来信等随机事件。
- **三个存档位**：可分别体验不同线路；旧版单存档会自动迁移到存档 1。
- **声音**：古筝拨弦（Karplus-Strong）与五声音阶旋律实时合成，城镇 / 野外 / 战斗 / 首领 / 悲伤 / 结局各有曲风，另有刀剑、拳脚、升级等音效，可在系统设置中开关。
- **江湖志**：查看章节目标、侠义值、人物好感、证物、结局收集和江湖纪事。

## 构建与发布

本地只做代码开发，不在本地构建。APK 由 GitHub Actions（`.github/workflows/android-apk-release.yml`）构建签名：

```bash
git tag -a v2.0.0 -m "Release v2.0.0"
git push origin v2.0.0
```

推送 `v*.*.*` 标签后，工作流会构建签名 APK，并以 `my_wuxia.apk` 的名字上传到对应 GitHub Release。签名依赖组织级 Actions 配置 `KEY_JKS`、`ALIAS`、`ANDROID_KEY_PASSWORD`、`ANDROID_STORE_PASSWORD`（工作流会自动去除这些值中的 UTF-8 BOM 与换行）。

## 代码结构

| 文件 | 说明 |
| --- | --- |
| `MainActivity` / `GameView` | 全屏 Activity 与 720 宽虚拟画布，处理音频生命周期 |
| `Game` / `Scene` / `Button` | 场景切换、触控分发、多存档、设置、结局收集 |
| `Audio` | 程序合成的背景音乐与音效 |
| `GameData` | 门派、武功、物品与兵器、敌人、地点数据（只追加，保证存档兼容） |
| `Player` / `Inventory` | 角色成长、装备加成、JSON 存档与旧版迁移、物品 / 装备 / 强化 |
| `Story` / `Ev` | 章节目标、分支事件、随机奇遇、多结局 |
| `DialogScene` / `EndingScene` | 对白与抉择、结局卡片 |
| `*Scene` | 标题、存档位、创建角色、地点、地图、战斗、集市、铁匠铺、武学、行囊、江湖志、系统 |
| `UI` / `Sprites` | 水墨风背景、面板、人物立绘与野兽绘制 |
